CAMPUSSPACE - WEBSITE UTS IMK

1. Ganti data contoh di index.html: nama, NIM, program studi, fakultas, dan email.
2. Ganti informasi kampus di kampus.html.
3. Masukkan foto ke folder images dengan nama berikut:
   profil.jpg
   logo-kampus.png
   kampus.jpg
   foto1.jpg sampai foto6.jpg
4. Pastikan struktur folder:
   galeri-mahasiswa/
     index.html
     kampus.html
     galeri.html
     images/
       (seluruh gambar)
5. Buka index.html untuk melihat website.
6. Upload seluruh isi folder ke repository GitHub, lalu aktifkan GitHub Pages.

Catatan: File gambar tidak disertakan; gunakan foto milikmu sendiri.
